# 성일의 꿀템 모음zip

쇼츠·릴스·틱톡·블로그에서 모인 방문자를 **번호 하나로 상품에 연결**하는 상품 큐레이션 페이지예요.
쿠팡 파트너스 링크를 이 페이지에 모아 두고, 영상에서는 "프로필 링크에서 01번 확인하세요!"라고만 안내하면 됩니다.

- 사이트: https://projectmoon90.github.io/
- 순수 정적 파일이라 서버·유지비가 없고, GitHub Pages에 그대로 올라가 있어요.

## 파일 구조

```
index.html        화면 뼈대 (보통 건드릴 일 없음)
styles.css        디자인 (색·간격은 :root 변수에서)
app.js            검색·카테고리·카드 렌더링
site.json         ⭐ 사이트 제목·소개문·채널 링크·안내 문구
products.json     ⭐ 상품 목록 (여기만 고치면 사이트가 바뀝니다)
assets/favicon.svg
```

## 상품 추가하는 법

`products.json`의 `products` 배열에 아래 형식으로 한 덩어리 추가하고, 맨 위에 커밋해서 올리면 끝이에요.

```json
{
  "no": "07",
  "category": "life",
  "name": "상품 이름",
  "pitch": "한 줄 추천 포인트 (15~30자 정도가 예뻐요)",
  "price": "9,900원대",
  "tags": ["태그1", "태그2"],
  "emoji": "🧴",
  "image": "",
  "url": "https://link.coupang.com/a/실제파트너스링크"
}
```

| 항목 | 설명 |
| --- | --- |
| `no` | 화면에 `#07`로 보이는 고유 번호. 영상에서 부를 번호와 같게 두 자리로 맞춰 주세요. |
| `category` | `products.json` 위쪽 `categories`의 `id` 값 (`toy`, `life`, `value`) |
| `name` / `pitch` / `price` / `tags` | 카드에 표시되는 이름, 한 줄 소개, 가격대, 태그 |
| `emoji` | 썸네일 자리에 들어갈 이모지 (이미지가 없을 때 사용) |
| `image` | 실제 상품 이미지 주소. 비워 두면 이모지 썸네일이 나와요. |
| `url` | 쿠팡 파트너스 링크. `"#"`이면 데모 상태로, 누르면 안내 문구만 떠요. |

새 카테고리를 만들려면 `categories`에 `{ "id": "kitchen", "label": "주방템", "emoji": "🍳", "theme": "life" }`처럼 넣고,
상품의 `category`에 그 `id`를 적으면 탭이 자동으로 생겨요. (`theme`: `toy` / `life` / `value` 중 하나 — 썸네일 색)

## 사이트 제목·문구 바꾸기

`site.json`에서 바꿉니다.

- `brand.title` — 상단 큰 제목
- `brand.tagline` — 제목 아래 한 줄 소개
- `brand.emoji` — 제목 옆 아이콘
- `searchHint` — 검색창 안내 문구
- `disclosure` — 공정위 대가성 문구 (지우면 안 되는 문구예요)
- `channels` — 아래쪽 유튜브·인스타·틱톡·블로그 버튼 (`url`을 채우면 나타나요)

## 영상과 연결하는 법

- 영상 설명란·고정댓글: `프로필 링크(https://projectmoon90.github.io/)에서 01번 확인하세요!`
- 카드 오른쪽 위 **링크 아이콘**을 누르면 그 상품만 보이는 주소(`.../#p-01`)가 복사돼요. 영상별로 이 링크를 써도 좋아요.
- 방문자가 번호를 몰라도 검색창에 `01`, `1번`, 상품명, 태그를 치면 바로 걸러져요.

## 직접 미리보기

```bash
cd coupang-hub
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

> `index.html`을 더블클릭(file://)하면 브라우저 보안 정책 때문에 `products.json`을 읽지 못해요.
> 로컬 서버로 열거나, 이미 올라가 있는 https://projectmoon90.github.io/ 를 확인하세요.

## 꼭 지켜야 할 것 (쿠팡 파트너스)

- 쿠팡 파트너스 가입 시 **활동 채널에 이 사이트 주소를 등록**해야 해요.
- 링크를 올리는 모든 곳(영상 설명란, 블로그, 인스타)에 **대가성 문구**를 넣어야 해요.
  이 사이트는 상단과 하단에 문구가 들어가 있고, 영상 설명란에도 같은 문구를 넣어 주세요.
- 수수료율·정책은 쿠팡 파트너스 기준을 따르며, 상품 가격은 수시로 바뀔 수 있어요.
